# Kaggle dataset source

This project uses one dataset only:

**The Movies Dataset** — https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset

The project uses the original CSV files supplied in the uploaded Kaggle archive. No rows are fabricated and no replacement dataset is mixed in.

| File | Original rows (approx.) | Purpose |
|---|---:|---|
| `movies_metadata.csv` | 45,466 | Movie metadata and ratings |
| `ratings_small.csv` | 100,004 | MovieLens user ratings |
| `keywords.csv` | 46,419 | Movie keyword tags |
| `links_small.csv` | 9,126 | MovieLens/TMDB ID mapping |

The full `ratings.csv` and `credits.csv` are not required by this implementation and are intentionally left out to reduce project size.
