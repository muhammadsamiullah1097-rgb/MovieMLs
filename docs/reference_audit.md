# Reference module coverage

This project keeps the machine-learning scope identified in the supplied midterm project references and adapts the input features to The Movies Dataset. No classmate code or saved model was copied.

| Module area | Included work |
|---|---|
| Classification models | Logistic Regression, class-weighted Logistic Regression, Decision Tree Gini, Decision Tree Entropy, Random Forest, Bagging, AdaBoost, Gradient Boosting, SVM, Gaussian Naive Bayes, KNN, majority baseline |
| Regression models | Simple Linear, Multiple Linear, Polynomial, Ridge, Lasso, Decision Tree, Random Forest, KNN Regressor |
| Text modules | Text cleaning/tokenization helper, TF-IDF + Naive Bayes, CountVectorizer + Naive Bayes |
| Preprocessing | Missing-value imputation, duplicate inspection, one-hot encoding, label/frequency encoding helpers, Standard/Min-Max/Robust scaling, SMOTE |
| Feature engineering | RFE and PCA |
| Evaluation | Accuracy, precision, recall, F1, balanced accuracy, MCC, confusion matrix, ROC-AUC where applicable; MAE, MSE, RMSE, R-squared and median absolute error |
| Dataset-specific addition | Content-based and collaborative movie recommendations using the supplied Kaggle CSV files |

The two recommendation methods are added because the selected Movies Dataset includes both movie descriptions/keywords and a separate user-rating table. They do not replace the midterm model modules.
