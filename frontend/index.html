—MOVIE RECORDS

How the data is used

Classification: predict a Low, Medium or High rating tier from metadata. The target is derived from the source's vote_average column.

Regression: predict the numeric vote_average value.

Text classification: predict the primary genre from the movie overview text.

Recommendation: content-based TF-IDF uses movie descriptions and keywords. Collaborative filtering uses MovieLens user ratings and the links_small ID map.

The large ratings.csv and credits.csv files are not needed for these modules; ratings_small.csv is used to keep the project lightweight.
